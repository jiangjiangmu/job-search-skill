# HR 沟通开场白模板

## 原则
1. 短（3-5 句话，HR 没耐心看长文）
2. 直击岗位核心需求
3. 用具体事实代替形容词（"我部署过" > "我熟悉"）
4. 展示对公司的了解（一句话即可）

## 模板结构
```
您好，看到贵司在招 <岗位名>。
<一句话：我最匹配的核心能力/经历>
<一句话：跟岗位具体要求挂钩的细节>
<一句话：表达兴趣 + 期待沟通>
```

## 示例（岗位为虚构）

### 后端开发岗（示例）
> 您好，看到贵司在招后端开发工程师。
> 我有 3 年 Python 后端 + AI 工具落地经验：独立开发并持续维护过一个带完整自动化测试的生产级内部工具平台。
> 贵司 JD 里的「{{核心要求}}」正是我反复做过的方向。期待沟通！

## 注意事项
- 不说"我学习能力强"这类空话——用项目说话
- 薪资不在开场白里谈（等 HR 问或面试阶段）
- 如果 HR 长时间不回，24h 后可跟一条（不催不闹）
