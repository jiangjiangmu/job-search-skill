# 能力画像模板（示例）

> 这是 job-search-skill 的个性化配置文件：把示例换成你自己的真实画像。
> `job-analyze` 的匹配度评估全部对照本文件打分——画像越具体，评估越准。

## 怎么填

- 每个能力条目都要能被 JD 关键词直接命中（「Python 自动化」优于「会编程」）
- 项目经历用数字说话：代码行数、测试数、版本数、用户数
- 求职意向写清方向、城市、薪资线——这是评分引擎的基准
- 本文件含个人画像，属敏感内容；自用时注意不要提交到公开仓库（哨兵会拦邮箱/手机号）

## 示例画像（人物为虚构）

> 示例：3 年运维 + AI 工具重度使用者，转型 AI 应用方向

### 技术能力

- **Python 与工程化**：办公流程脚本、数据提取、批量文件处理；写过带单元测试的小型工具
- **AI 工具链**：LLM API 集成、Prompt 设计、Agent 工作流编排、多模型调度
- **运维底子**：Windows/Linux 桌面支持、局域网排障、IT 资产管理、远程运维
- **自动化**：屏幕自动化（截屏/键鼠注入）、OCR、定时任务、文档管理

### 旗舰项目（示例写法）

**XX 自动化平台**：个人独立开发的生产级工具，N 行代码 + N 个自动化测试 + N 个版本迭代，覆盖「输入 → 处理 → 落库」完整闭环；零第三方依赖、API Key 自动脱敏、Schema 版本化迁移。

### 求职意向（示例）

- **方向**：{{AI 应用工程师 / AI Agent 开发 / AI 自动化运维}}
- **城市**：{{城市}}（{{通勤半径}} 内优先）
- **薪资**：{{面议 / 具体区间}}
- **到岗**：{{随时 / 需交接 N 周}}
