# 岗位分析模板

## 输入方式
- 方式一：截图职位详情页（我会 OCR 提取）
- 方式二：直接粘贴职位描述文字

## 分析流程

### 1. 基本信息提取
| 字段 | 内容 |
|---|---|
| 职位名称 | |
| 薪资范围 | |
| 城市/区域 | |
| 经验要求 | |
| 学历要求 | |
| 公司名/规模/融资 | |
| HR 信息 | |
| 距离（如显示）| |

### 2. 职责拆解
逐条列出岗位职责，标注：
- 【核心】：必须胜任的关键职责
- 【加分】：锦上添花
- 【坑】：可能与薪资不匹配的隐性要求

### 3. 薪资水位判断
- 该城市该岗位的市场区间
- 该公司给的薪资在区间内的位置（偏低/合理/偏高）
- 议价空间

### 4. 匹配度评估
对照能力清单：
- 匹配度：高/中/低（百分比）
- 优势：我比要求强的地方
- 劣势：我欠缺或薄弱的地方
- 红旗：值得警惕的信号

### 5. 行动建议
- 建议投递：是/否/犹豫
- 话术重点：如果投，开场白应该突出什么
- 谈薪策略：如果进入面试，薪资怎么谈

## 输出
分析完成后存入 `已分析岗位\<公司名-岗位名-日期>.md`
