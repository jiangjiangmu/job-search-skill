# job-analyze 岗位分析技能

## 触发条件
当用户发来职位截图/链接/文字描述，说"分析这个岗位""这个值得投吗"时激活。

## 执行流程
1. 提取基本信息（截图用 OCR / 文字直接解析）：职位名/薪资/城市/经验/学历/公司/HR
2. 职责拆解：标注【核心】【加分】【坑】
3. 薪资水位判断：对照市场区间给"偏低/合理/偏高" + 议价空间
4. 匹配度评估：对照 references/能力清单.md，给 高/中/低 + 优势/劣势/红旗
5. 按 references/scoring-rubric.md 统一口径打分
6. 行动建议：投/不投/犹豫 + 话术重点 + 谈薪策略

## 输出契约
文件名：<公司名-岗位名-日期>.md
结构：基本信息表 → 职责拆解 → 薪资水位 → 匹配评估 → 行动建议

## 注意事项
- 截图分析前先 OCR 提取完整文字，不凭肉眼猜数字
- 匹配度必须有依据（对照能力清单具体条目），不空喊
